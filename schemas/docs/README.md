# Vitae Documentation Schemas

This directory contains the canonical JSON Schemas for Vitae documentation frontmatter.

- `common.schema.json` contains shared definitions.
- `adr.schema.json` validates ADR frontmatter.
- `prd.schema.json` validates PRD frontmatter.

New schemas should use JSON Schema draft 2020-12 and should keep shared definitions in `common.schema.json` when possible.
