# Product Requirements Documents

Use PRDs to align on product problems, users, requirements, success measures, and scope before implementation.

- Template: `templates/docs/prd-template.md`
- Schema: `schemas/docs/prd.schema.json`
- Standard: `docs/documentation-standards.md`

File naming convention:

```text
docs/prd/short-product-or-feature-title.md
```

Keep one coherent product problem or initiative per PRD.
