# Architecture Decision Records

Use ADRs to capture one architecture-significant decision at a time.

- Template: `templates/docs/adr-template.md`
- Schema: `schemas/docs/adr.schema.json`
- Standard: `docs/documentation-standards.md`

File naming convention:

```text
docs/adr/0001-short-decision-title.md
```

Keep titles decision-oriented rather than problem-oriented.
