# Feature: Embedding-based Category Detection

Implement embedding-based logic to classify resumes and job descriptions into profile categories (Industry, Function, Seniority, etc.) using semantic similarity.

## Story: Embedding-based Category Detection

### Task: Integrate sentence-transformers or similar embedding model
- Research and select a suitable embedding model (e.g., sentence-transformers, OpenAI, or local LLM)
- Add model to backend dependencies and environment
- Implement utility to generate embeddings for relevant resume/job sections

### Task: Generate canonical category vectors
- Define canonical descriptions/examples for each profile category (Industry, Function, Seniority, etc.)
- Generate and store embeddings for these canonical categories

### Task: Compare document embeddings to category vectors
- Implement logic to compare section embeddings to category vectors (cosine similarity)
- Assign categories based on highest similarity scores

### Task: Test and validate detection
- Create a set of sample resumes and job descriptions
- Evaluate detection accuracy and adjust thresholds/logic as needed
