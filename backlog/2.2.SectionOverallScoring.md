# Feature: Section-level and Overall Similarity Scoring

Implement logic to compare resume sections/bullets to job requirements and aggregate to an overall match score.

## Story: Section-level and Overall Similarity Scoring

### Task: Implement section-level similarity scoring
- Compare resume sections/bullets to job requirements using cosine similarity
- Return similarity scores for each section/requirement pair

### Task: Aggregate to overall match score (0-100%)
- Design aggregation logic (weighted average, custom formula, etc.)
- Expose overall score in API responses
